## Why

Jig already has typed targets, profiles, affected selection, durable runs,
and current-evidence reuse.
Default guidance still teaches overlapping commands and includes specialized
details unrelated to many tasks.
Astra's documented instruction sensitivity and thorough verification behavior
make these worthwhile hypotheses to test, not proven performance improvements.

## Acceptance criteria

- Every audit recommendation maps to a delivered child outcome or a justified rejected experiment.
- Root and shipped guidance use a shorter accurate workflow.
- Current evidence satisfies required verification without redundant procedural commands.
- Specialized guidance remains discoverable and important invariants are preserved.
- Scoped inspection exposes owners, guide paths, candidates, uncertainty, and freshness policy.
- MCP result contracts and selected compact projections preserve standard-client compatibility.
- Acceptance criteria distinguish executable evidence from attestations and preserve old plans.
- Astra comparisons use fixed baselines, objective graders, and actual recorded results.
- Init, full/minimal adoption, update, and recopy remain compatible.
- Required implementation gates pass and no child is closed on expected results alone.

## Boundaries

Keep typed effects, exact execution authority, freshness checks, cancellation,
owned-process supervision, privacy, and append-only history.
Preserve minimal footprint semantics and unmanaged local guidance.
Do not introduce mandatory subagents, mandatory review loops, automatic global
agent setup, a second issue tracker, or arbitrary agent-supplied shell execution.
Compact plan handles are conditional on task 11's measured decision.
A conclusive rejection is a valid outcome; an inconclusive experiment is not.
