## Decision Log

- Keep absolute-deadline ownership in each specialized runner while sharing the complete Linux
  `/proc` scan. The shared function accepts a validated `ProcessGroupId` and absolute `Instant`.
- Keep caller-specific failure context in thin Vault and proxy adapters. The shared scanner returns
  `std::io::Error` with its original stat/enumeration error retained as a source.
- Accept a safe `BorrowedFd` in the shared nonblocking helper. Vault uses one pipe enum while its
  transparent and brokered callers retain distinct unsupported-platform messages and policies.
