## Context and Orientation

`crates/jig/src/bootstrap/scaffold.rs` turns public `ScaffoldPreset` values into an `InitScaffoldPlan`. Rust library and Rust CLI both use `ScaffoldProjectPlan::RustOnly` and the shared renderer in `crates/jig/src/bootstrap/scaffold/rust_only_workspace.rs`. The renderer owns five project files: root `Cargo.toml`, root `README.md`, `crates/<package>/Cargo.toml`, `crates/<package>/AGENTS.md`, and exactly one source file. The library source is `src/lib.rs`; the CLI source is `src/main.rs`.

The full harness is rendered separately from `templates/project`. `materialize_template_git_worktree` in `crates/jig/src/bootstrap/tests.rs` produces a generic committed template fixture. Public `run_init` composes harness and scaffold output, validates the complete planned path set, starts an `InitMutationTransaction`, publishes through guarded staging, initializes Git, and rolls back owned generations on failure.

An “embedded snapshot” is the checked-in copy of template bytes compiled when live checkout templates are unavailable. `crates/jig/build.rs` selects live templates normally and snapshot files when `JIG_EMBEDDED_TEMPLATE_SNAPSHOT` is set. The test modules in `crates/jig/src/bootstrap/embedded_templates.rs` and `bootstrap/scaffold/embedded_templates.rs` already prove raw source parity. B06 adds the observable missing step: both Rust-only contexts must render identical relative paths and bytes from either source array.

The B03/B04 positive oracles live in `crates/jig/src/bootstrap/tests/basic/scaffold_generation_parts/rust_library.rs` and `rust_cli.rs`. They assert exact scaffold reports; required and forbidden paths; parseable Cargo manifests; one resolvable member; license-neutral, non-publishable packages; SQLx/application-contract/frontend/dev disablement; neutral `workspace` components and Rust actions; crate guide discovery; root guidance; offline setup; format; strict Clippy; locked tests; rustdoc; project ownership on update; and exact CLI execution. B06 must compose these facts without weakening their exact artifact-specific assertions.

Transaction coverage lives in `crates/jig/src/bootstrap/tests/basic/init_safety.rs` and `init_safety_parts/`. A transaction retains preimages and each Jig-published generation so rollback can restore admitted bytes and modes without overwriting concurrent foreign changes. The generation budget caps unique planned leaves plus repeated publications and reserves directory, staging, and descriptor headroom. B06 adds representative Rust-only public paths to this generic proof.

Public JSON and human process tests live in `crates/jig/tests/cli_json.rs` and `cli_json_parts/rust_cli.rs`. `crates/jig/src/cli/bootstrap_run_tests.rs` owns exact descriptor JSON and human summaries. JSON mode must write one parseable object to stdout and keep stderr empty, including usage or policy errors.
